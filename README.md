FitLog — Workout Library & Planner

FitLog is a dark, no-nonsense gym companion web application built for fitness enthusiasts to browse workouts, build daily plans, and track their fitness journey efficiently.

 Technologies Used

- Next.js (App Router) - For building the user interface and handling page routing.
- Tailwind CSS - For modern, responsive styling and layout design.
- React - For building interactive user interfaces and managing component state.
- TypeScript - For type safety and a robust code structure.
- LocalStorage API - For persisting workout plans and saved items across page reloads.

 Key Features

1.Comprehensive Workout Library: Explore a collection of exercises with muscle groups, equipment requirements, duration, and calorie estimates.

2.Interactive Search & Filter: Quickly find specific workouts by searching their names or filtering by muscle groups.

3.Daily Plan & 5-Lift Cap:Add up to 5 exercises to "Today's Plan" to keep workouts focused and structured.

4.Persistent Storage:Save and manage workouts and daily plans that remain available after page refreshes using LocalStorage.

5.Responsive & Modern UI: Fully responsive design optimized for mobile, tablet, and desktop screens with smooth navigation and user-friendly interactions.
